# Курс C# с нуля

Статический сайт-учебник: 7 уроков, 6 видеоразборов и второй модуль. Никаких сборок и зависимостей — открывается двойным щелчком по `index.html`.

> 🤖 Проект создан с помощью ИИ.

## Что внутри

**Модуль 1 — основы**

| Урок | Тема |
|---|---|
| 01 | C# и .NET, первая программа |
| 02 | Переменные и типы |
| 03 | Условия и циклы |
| 04 | Массивы и списки |
| 05 | Методы |
| 06 | Классы и ООП |

**Модуль 2 — надёжный код**

| Урок | Тема | Статус |
|---|---|---|
| 07 | Исключения и отладка | готов |
| 08 | Файлы и JSON | план |
| 09 | Интерфейсы | план |
| 10 | Dictionary и HashSet | план |
| 11 | LINQ | план |
| 12 | async / await | план |

## Возможности сайта

- светлая и тёмная тема, выбор запоминается;
- прогресс прохождения уроков в `localStorage`;
- подсветка синтаксиса C# собственным токенайзером (без CDN — работает офлайн);
- кнопка «Копировать» у каждого примера;
- мини-тесты с пояснениями и задания со спрятанными решениями;
- интерактивные «видео»: набранный по буквам код, консоль, пауза, перемотка по главам.

## Структура

```
index.html            главная: программа курса и прогресс
lesson-01..07.html    уроки
video-01..06.html     интерактивные видеоразборы
module-02.html        программа второго модуля
assets/css            стили сайта и плеера
assets/js             логика, сценарии видео, подсветка
assets/img            восемь схем в SVG (нарисованы вручную)
```

## Запуск

Открыть `index.html` в браузере. Всё локальное, интернет не нужен.
